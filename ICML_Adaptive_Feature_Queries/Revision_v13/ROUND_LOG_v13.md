- Theorem 3(c) / Theorem (binary pointer tree): for the depth-(b−1) binary pointer tree (tree evaluation instance), V_r >= 2^{b−1}/[r b (1+2b/(r−1))^{r−1}] >= 2^{b−1}/(3b)^r for 2<=r<=b, so sup V_2/V_branch in [2^{b−2}/(b(2b+1)), 2^{b−2}] and the r-round exponent is b − O(r log b); Omega(b/log b) rounds are needed to be within poly(b) of branching.
