- 本轮新增的内容：
  - "多问几题"定理：表单多问 c 题，最坏情形的代价最多除以 c+1（地址函数恰为 2^{b−1}/(c+1)）；多项式维度下即使表单长一倍仍损失 2^{b(1−o(1))}；平均预算下亦有一般结论。
  - 目标族命题：若要同时估计所有 b 次单项式，均匀表单在所有设计（含分支）中已是最优——代价是"定向采集"特有的。
  - 真实规则上的曲线：52 条规则上，表单/分支的记录数比值中位数 1.47；多问 1 题降到 1.14，多问 2 题降到 1.02。
  - 按"问题数"而非"记录数"计：三种预先确定的设计都要多花约 1.4–1.5 倍的问题，多问几题省不了问题。
  - 最宽的 5 条规则（题项超过 13）用路径集程序给出有效上界 2.2–4.0。
- 审稿人的结论：这些新结果都被认可（R1 称目标族命题和条件独立结论"值得有"，R2 称按问题数的结论"更稳健"），但分数不变。

## 现在可以下的判断
- 第 9、10、11 三轮正式评审加上本轮彩排，同一类审稿人四次独立抽样、四个不同版本，结果都是 R1=3、R2=4、R3=3。这是稳定结果，不是在"接近三个 4"附近的波动。
- 三位审稿人给出的理由一致，而且针对的是选题而不是执行：
  1. 主定理对 ML 理论审稿人来说是"民间结论的精确化"，技术上浅；
  2. 指数级差距需要刀刃条件（单一已知目标、上限等于树深、约 2^{b−1} 个相关特征），训练出的规则远达不到；
  3. 实际代价只有 1.0–2.4 倍，多问一两题、加一轮追问或用工作模型即可消除；
  4. ML 场景的动机不成立（R3 指出：设备可以本地执行整棵树再一次性回传）。
- 剩下能加分的要求都不是"再改一轮"能做到的：按"超出树深的相关题项数"给出紧到常数的定理、紧的两轮界（新研究，结果不确定）；真实审计、强制预先承诺的真实场景（没有这类资源）；带权重的大规模实验、多规则设计（等于另一篇论文）。
